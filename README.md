# Spuki

바탕화면에 작은 스피커 한 대를 올려 두는 macOS 앱입니다. Mac에서 나오는 모든 소리에 EQ를 적용합니다.

A desktop speaker for macOS that puts a system-wide EQ on everything your Mac plays.

**https://waterbinnn.github.io/spuki/**
